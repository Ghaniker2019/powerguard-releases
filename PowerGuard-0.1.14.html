PowerGuard 0.1.14

  • Nouveau — Fraîcheur des données Claude. Les limites (compte entier) ne se rafraîchissent qu'aux requêtes de Claude Code : si vous consommez des tokens sur claude.ai (web/app) pendant que Claude Code est inactif, l'app l'indique désormais clairement (« synchro il y a X · usage web/app récent non compté ») au lieu d'afficher un 0 % trompeur.
  • Nouveau — Tant qu'aucune synchro n'a eu lieu pour la fenêtre en cours, la jauge affiche « — » (en attente) plutôt qu'un 0 % qui laisserait croire à un quota plein. L'onglet Claude Sync montre l'heure de dernière synchro.
